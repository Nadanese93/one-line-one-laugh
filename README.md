A single funny line for the [One Line, One Laugh](https://make.fun/bounty/u-4z4ghtbwm1fn7mibrqum4bxgfghhgqzriyhd8v3-one-line-0be61e5a) bounty on make.fun.

Running `main.py` writes one self-contained joke (1–140 characters) to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).

## The line

> The dentist asked how my teeth were doing while both his hands were in my mouth, so I just nodded like a hostage.

## Usage

```sh
python3 main.py
```
